# הכתבה בעברית ל-Mac (fn+Shift)

הכתבה מהירה בעברית לכל אפליקציה ב-Mac. מחזיקים `fn+Shift`, מדברים, משחררים — הטקסט מודבק במקום שהסמן נמצא.

**מרגע השחרור ועד ההדבקה: כ-0.6 שניות** (נמדד).

התמלול רץ ב-[Groq](https://console.groq.com) על `whisper-large-v3`. יש שכבה חינמית נדיבה, וצריך רק מפתח API.

---

## התקנה

צריך **Hammerspoon** ואת **כלי שורת הפקודה של Xcode**:

```bash
brew install --cask hammerspoon
xcode-select --install
```

ואז:

```bash
git clone <repo-url> hebrew-dictation
cd hebrew-dictation
./install.sh
```

הסקריפט יבקש מפתח Groq ([להשגה כאן, חינם](https://console.groq.com/keys)).

### שתי הרשאות ידניות

macOS לא מאפשר לסקריפט לתת אותן. צריך ידנית:

- **הגדרות מערכת ← פרטיות ואבטחה ← נגישות** ← לאפשר ל-Hammerspoon
- **הגדרות מערכת ← פרטיות ואבטחה ← מיקרופון** ← לאפשר ל-Hammerspoon

אחר כך להפעיל את Hammerspoon (או `Ctrl+Cmd+R` לטעינה מחדש).

## שימוש

מחזיקים `fn+Shift`, מדברים, משחררים.

יש **שתי התראות והן אומרות דברים שונים**:

| התראה | מה זה אומר |
|---|---|
| ⏳ מתחבר | המיקרופון עוד נפתח — **מה שתגיד עכשיו יאבד** |
| 🎙️ מקליט | האודיו באמת נקלט, אפשר לדבר |

פתיחת המיקרופון לוקחת בערך חצי שנייה. כדאי לחכות ל-🎙️.

טיפ: אם לוחצים על `fn` רגע לפני ה-`Shift`, המיקרופון מתחיל להיפתח מוקדם והעיכוב כמעט נעלם.

## התאמה אישית

הכל בקובץ `~/.hammerspoon/dictation.lua`. אחרי כל עריכה — `Ctrl+Cmd+R`.

### מילון מונחים

`VOCAB_PROMPT` מטה את אוצר המילים של המתמלל. **זה החלק הכי משתלם לערוך.** כדאי להוסיף שמות של אנשים, לקוחות, מוצרים, וכל מילה שהמנוע טועה בה שוב ושוב.

המילון שמגיע כברירת מחדל מכוון לעברית של הייטק. במדידה, הוא שינה את התוצאה כך:

| בלי מילון | עם מילון |
|---|---|
| הבואג | ✅ הבאג |
| צ'יקאות | ✅ צ׳קאאוט |
| הדיפלויל פרודקשן | ✅ הדיפלוי לפרודקשן |

**זה לא עולה זמן.** ההטיה קורית בתוך התמלול עצמו.

### קיצור אחר

`isExactFnShift` ו-`isPrimingModifierOnly`. אם משנים, כדאי לשים לב לדבר אחד: **לא לחמם את המיקרופון על `Shift` לבד** — לוחצים עליו כל הזמן בהקלדה רגילה, והמיקרופון ייפתח עשרות פעמים בדקה.

### שפה

`LANGUAGE = "he"` — עברית קבועה, וזו ברירת המחדל בכוונה.

ניסינו זיהוי אוטומטי (`LANGUAGE = nil`) והוא הרע את איכות העברית בשימוש אמיתי — Whisper מנחש לפעמים שפה לא נכונה והפלט מתדרדר. כשכמעט כל ההכתבה בעברית, לכפות `"he"` פשוט עובד טוב יותר.

לשפה אחרת: כל קוד ISO-639-1 (`en`, `ar`, `ru`...). לזיהוי אוטומטי: `LANGUAGE = nil`.

## פתרון בעיות

`~/.hammerspoon/dictation.lua` כותב לוג מפורט. לצפייה:

```bash
hs -c 'for _,l in ipairs(_G.dictationLog) do print(l) end' | tail -20
```

כל תמלול רושם את הטקסט שחזר ואת הזמן מהשחרור ועד ההדבקה.

### להשוות מנועים על הקלטה אמיתית

צריך קודם להדליק שמירת הקלטות — `KEEP_RECORDINGS = true` ב-`dictation.lua` (כבוי כברירת מחדל). אחרי כמה הכתבות:

```bash
~/.hammerspoon/bin/compare-transcribers.sh
```

מריץ את ההקלטה האחרונה דרך Groq עם מילון, בלי מילון, `turbo`, ו-ElevenLabs (אם יש מפתח ב-`~/.config/dictation-elevenlabs-key`) — ומראה את התוצאות זו לצד זו.

### תקלות נפוצות

| תסמין | סיבה |
|---|---|
| "ההקלטה לא נקלטה" | אין הרשאת מיקרופון ל-Hammerspoon |
| כלום לא קורה בלחיצה | אין הרשאת נגישות ל-Hammerspoon |
| תחילת המשפט נחתכת | דיברת בזמן ⏳. לחכות ל-🎙️ |
| יוצא ג'יבריש כשלא דיברת | Whisper ממציא טקסט משקט (לרוב "Thank you") — התנהגות ידועה של המודל |

## איך זה בנוי

```
fn+Shift ↓
  └─ bin/dictation-recorder   הקלטה מ-CoreAudio, 16kHz מונו
       └─ מדפיס READY כשהאודיו באמת זורם
fn+Shift ↑
  └─ curl → Groq whisper-large-v3
       └─ הדבקה בסמן (⌘V), הלוח משוחזר אחרי שנייה
```

**למה מקליט משלו ולא ffmpeg.** `ffmpeg -f avfoundation` לקח **1.4 עד 3.5 שניות** לפתוח את המיקרופון (נמדד). בהכתבה של 2-4 שניות זה בלע את רוב המשפט, והתוצאה נראתה כמו "תמלול לא מדויק" בזמן שהתמלול היה מצוין — הוא פשוט קיבל רסיס. המקליט הייעודי פותח ב-**~0.5 שניות** ובאופן עקבי.

**למה אין שכבת ניקוי עם LLM.** נבדקה. `llama-3.3-70b` החליף בשקט "צ׳קאאוט" ב"בדיקות" — שינוי משמעות, שגרוע יותר משגיאת תמלול כי אי אפשר לזהות אותו. `qwen3.6-27b` נכנס ללולאת חשיבה אינסופית. `VOCAB_PROMPT` עושה את אותה עבודה בלי הסיכון: הטיית אוצר המילים יכולה רק לבחור מילה טובה יותר ממה שנאמר, לא להמציא תוכן.

## פרטיות

**המיקרופון נפתח רק כשלוחצים על הקיצור**, אף פעם לא ברקע. לחיצה על `fn` לבד מתחילה לפתוח אותו מוקדם — ואם לא השלמת את הצירוף, התהליך נהרג וקובץ ההקלטה נמחק מיד, בלי שנשלח לשום מקום.

**האודיו נשלח ל-Groq** לצורך התמלול. מי שזה לא מתאים לו — [מדיניות הפרטיות של Groq](https://groq.com/privacy-policy/).

**הקלטות לא נשמרות לדיסק** אלא אם מדליקים `KEEP_RECORDINGS = true`.

מפתח ה-API נשמר ב-`~/.config/dictation-groq-key` בהרשאות `600`, ולא בתוך הקוד.
